# ⚡ Unified SEO Backlink & Indexing Suite

Dual-Engine Backlink & Crawler Indexing Platform:
- **Instant 10-Site API Blast Engine (2s Execution)**: Publishes curated reference pages across 10 high-authority platforms (`CentOS Paste DA 91`, `Graph.org DA 88`, `dpaste.org DA 78`, `Rentry.co DA 75`, `dpaste.com DA 75`, `Paste.rs`, `Termbin`, `ix.io`, `paste.c-net.org`, `NullPaste`).
- **Automated Search Crawler XML-RPC Pinger**: Pings `Ping-O-Matic`, `Weblogs.com`, and `Blo.gs` feeds upon publication.
- **Single-Chrome Browser Bookmarking Engine**: Automates `Diigo`, `Hatena Bookmark`, and `Pastelink` inside a unified persistent Chrome profile.
- **Real-Time Google Sheet Watcher (8s Polling)**: Automatically detects new links added to the topmost date section of a Google Sheet.
- **Cloud Access Control Gate**: Protected by real-time Google Sheet credential verification.

## Run
```bash
pip install -r requirements.txt
playwright install chromium
python unified_backlink_suite.py
```
